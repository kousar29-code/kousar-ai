# 🤖 Kousar AI

### Your Personal AI Assistant

Kousar AI is a personal AI chatbot built using **Python, Streamlit, and the OpenAI API**. It can have conversations, understand images, use camera input, and work with documents.

## 🚀 Live Demo

👉 [Try Kousar AI Live](https://kousar-ai-j64xgh5judcix6u7puxkpv.streamlit.app/)

## ✨ Features

- 💬 AI-powered conversations
- 🧠 Custom AI personality
- 🖼️ Image upload and image understanding
- 📷 Camera input
- 📄 PDF and document support
- 🗑️ Clear chat option
- 🌐 Live web deployment

## 🛠️ Technologies Used

- Python
- Streamlit
- OpenAI API
- Generative AI
- GitHub

## 📌 Project Purpose

This project was created to learn and demonstrate practical skills in **Artificial Intelligence, Generative AI, Python, API integration, and web application development**.
